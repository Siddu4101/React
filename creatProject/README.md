React Project Creation:

1. via crate-react-app: this is bit heavy compare to vite vite is much light weight and has better startup time.

```bash
npx create-react-app app-by-create-react-app
cd app-by-create-react-app
npm run start
```

1. via Vite: 

```bash
npm create vite@latest app-by-create-vite-latest
cd app-by-create-vite-latest
npm install
npm run dev
```
